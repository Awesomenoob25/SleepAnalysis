Help

Learn how to configure, record and analyse a sleep monitoring session.

Quick Start
  1. Open Configuration.
  2. Select your default camera.
  3. Set the Video Recording Location, Sleep Data Extract Location and Snapshot Location.
  4. Save the configuration.
  5. Open Capture & Logging.
  6. Enter a session name and choose the snapshot interval.
  7. Click Start Session before going to sleep.
  8. Click Stop Session when monitoring is complete.
  9. Open Analysis to review the saved session.
settings

The Setting page controls the main Sleep Monitor settings.

Setting Purpose
Default Camera Selects the webcam that Sleep Monitor will use by default.
Default Snapshot Interval Controls how often a snapshot image is saved during monitoring.
Video Recording Location Folder used for recorded video files.
Sleep Data Extract Location Folder used for sleep-position CSV data files.
Snapshot Location Folder used for saved snapshot images.
Sleep Position Classification

Sleep Monitor uses MediaPipe body landmarks and configurable thresholds to estimate the current sleeping position.

Position Description
Back The sleeper is lying face-up.
Left Side The sleeper is lying on their left side.
Right Side The sleeper is lying on their right side.
Stomach The sleeper is lying face-down.
Unknown A person is detected, but the available landmarks are not sufficient for a reliable classification.
No Person Detected MediaPipe could not detect a person in the current camera frame.
Classification Thresholds

These values can be changed from Configuration. The defaults are:

Threshold Default
Minimum Body Visibility 0.45
Side Position Shoulder Width 0.12
Side Position Hip Width 0.10
Back Position Face Visibility 0.60
Stomach Position Face Visibility 0.35
Landmark Visibility 0.40
Changing classification thresholds can affect classification results. Use the Reset Classification Defaults button in Setting to restore the original values.
Capture & Logging

The Capture & Logging page is used to start and stop overnight monitoring.

Before starting, enter a meaningful Session Name. For example:

Shoaib_Night_01

While monitoring is running, Sleep Monitor:

  • captures video from the selected camera;
  • detects body landmarks using MediaPipe;
  • estimates the current sleeping position;
  • stores sleep-position data in CSV format;
  • saves video to the configured recording folder;
  • saves snapshots using the selected interval; and
  • displays live sleep-position statistics.
Analysis

The Analysis page reads CSV files from the configured Sleep Data Extract Location.

Select one session for detailed analysis, or hold Ctrl while clicking to select multiple sessions.

Sleep Monitor also attempts to match each CSV session with a recording stored in the configured Video Recording Location.

Troubleshooting

Check that the camera is connected, close other applications that may be using it, then select another camera from Configuration or Capture & Logging.

Open Configuration and confirm that the Sleep Data Extract Location points to the folder containing your CSV files. Save the configuration and reopen Analysis.

Check that Video Recording Location points to the correct recordings folder. The recording and CSV should belong to the same session.

Check camera positioning, lighting and whether the sleeper is visible. You can also test the classification thresholds under Configuration. Make small changes and validate the results before using the new settings.

Open Setting and click Reset Classification Defaults, then click Save Setting.
